# StayEasy File Naming Standard

Status: Approved  
Owner: StayEasy Management  
Review frequency: Annually

## Standard

- Use lowercase `snake_case` for new folders and code-safe working files.
- Use `YYYY-MM-DD` at the start of dated documents: `2026-07-23_campaign_report.md`.
- Client deliverables: `YYYY-MM-DD_client_subject_status.ext`.
- Templates: `subject_template_v01.ext`.
- Preserve existing filenames when scripts, links, Git history, or deployment may depend on them.
- Avoid spaces and special characters in technical paths.
- Use version numbers only for meaningful releases; do not create `final_final` variants.

## Status metadata

Important documents must state one status near the top: `Draft`, `In Review`, `Approved`, `Superseded`, or `Archived`.

## Lifecycle

Move superseded or questionable material to `archive/YYYY/YYYY-MM-DD_description/`. Never delete business records without explicit approval and an applicable retention check.
